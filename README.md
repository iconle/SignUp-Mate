# 报名助手

适用于 Windows，可辅助打开报名入口、填写个人信息和提交问卷。不同活动的页面可能不同，不能保证所有问卷都能自动处理，以网页显示的报名成功结果为准。

## 一、首次准备

1. 安装 Python 3.10 或更新版本：[官方下载](https://www.python.org/downloads/)。安装时勾选 **Add Python to PATH**。
2. 将分享 ZIP **完整解压**到本机可写的文件夹，不要直接在压缩包中运行。
3. 双击 **start.bat**。首次运行会自动创建运行环境、安装依赖并下载 Chromium 浏览器，需要联网，请等待安装结束。
4. 根据提示输入自己的姓名、学号、手机号码和班级。信息会保存到同文件夹的 `config.json`，以后沿用。

## 二、每次报名

双击 `start.bat`，根据提示输入：

- **报名链接**：粘贴完整的 `https://...` 链接；回车沿用上次链接。首次必须输入。
- **开始时间**：使用北京时间，支持 `2026-11-28 17:30:00`、`2026/11/28 17:30` 或 `17:30`（表示今天）。直接回车立即运行。过去的时间会要求重新输入。

示例：

```text
报名链接（回车沿用原链接）：
开始时间（……）：2026-11-28 17:30:00
```

浏览器会提前打开。保持电脑开机、联网且不休眠，不要关闭终端或浏览器。到指定时间后，脚本开始尝试报名。

## 三、自动执行的步骤

1. 勾选能够识别的“请先阅读／我已阅读”等阅读确认框。
2. 检测“立即报名”入口，按钮可用时点击。
3. 题目出现后按配置填写。目标用时为题目出现至点击提交随机 **3–4 秒**；若填写已超过目标时间，填完直接提交。网络、协议弹窗和验证码用时另计。
4. 所有识别到的题目填写成功后，点击提交一次；遇到“同意并继续”协议弹窗时自动确认。请在使用前自行阅读并确认接受活动协议和隐私条款。
5. 尝试识别成功提示。未识别到成功提示时不会重复提交，请检查浏览器。

有报名入口时保留原页等待；只有页面明确提示尚未开放且没有可见入口时才尝试刷新。默认等待开放最多 10 分钟，从设定开始时间到达后计算；立即运行时从页面打开后计算。

## 四、需要手动处理的情况

- 验证码、页面校验错误、名额已满或活动结束。
- 未配置的新题目、复杂选择题、矩阵题、联动题等。
- 页面结构不同，找不到报名入口、阅读确认框或提交按钮。

出现漏填或无法识别的题目时，脚本会暂停自动提交。请在浏览器中补齐并完成报名。终端显示“已点击提交”不代表报名成功，必须检查网页结果。

## 五、修改个人信息或题目匹配

用记事本打开同文件夹的 `config.json`，修改 `answers` 中的内容并保存，下一次运行生效。

```json
"answers": {
  "姓名": "你的姓名",
  "学号": "你的学号",
  "手机号码": "你的手机号",
  "班级": "你的班级"
}
```

左侧为题目中的独有文字，右侧为答案。例如页面题目叫“联系电话”，可将“手机号码”改为“联系电话”。选择题答案应与完整选项文字一致。若多个键匹配同一道题，脚本优先采用最长的键。

其他可选配置：

- `"auto_submit": false`：关闭自动提交，改为手动核对提交；默认开启。
- `"wait_open_seconds": 600`：等待开放的最长秒数，默认 600。
- `"refresh_interval_seconds": 5`：满足刷新条件时的最短刷新间隔，默认 5 秒，最低 3 秒。

编辑 JSON 时注意英文引号、逗号和括号，不要删除原有 `url`、`start_at`、`answers` 字段。链接和时间可在启动时输入，无需手动编辑。

## 六、常见问题

**提示安装 Python**：安装 Python 3.10 以上版本并勾选 Add Python to PATH，再重新双击 BAT。

**首次安装失败**：检查网络，保留终端中的完整错误信息；解决后重新运行 BAT。

**一直等待**：检查输入日期是否为今天、时间是否正确。终端会显示完整的开始时间。

**浏览器没有弹出**：首次安装可能尚未完成，请查看终端输出；如果报错，保留完整错误信息。

**想停止运行**：在终端按 `Ctrl+C`，或关闭终端及浏览器。完成后按提示回车关闭浏览器。

## 七、分享与个人信息

个人信息明文保存在本机 `config.json`。不要把填写后的文件夹、配置文件或含个人信息的截图发给别人。分享时请发送最初的空白配置分享 ZIP，让每个人填写自己的资料。
